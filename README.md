# 🎨 Creative Portfolio — Muhammad Prima Yudhistira

Website portofolio berestetika **High-Fashion Magazine Cover** dengan interaksi 3D dinamis (*Three.js*) dan *scroll-driven avatar choreography*.

---

## ✨ Fitur & Interaktivitas

### 1. Hero Section (Sampul Majalah Editorial)
- **Latar Belakang Krim Mewah (*Warm Editorial Cream* `#f6f4f0`)**.
- **Tipografi Raksasa Merah Menyala (*Bold Editorial Crimson Red* `#d11a2a`)**:
  - `MUHAMMAD`
  - `PRIMA` (**Hero Centerpiece raksasa**)
  - `YUDHISTIRA`
- **Efek Tumpuk 3D (*3D Sandwich Text-Stroke Effect*)**:
  - Teks solid di belakang karakter, karakter 3D di tengah, teks *outline* di depan karakter.
  - Setiap huruf yang menimpa tubuh karakter otomatis berubah menjadi *wireframe outline*.
- **Animasi Peeking saat Buka Web / Scroll ke Atas**:
  - Karakter mulai dari 100% tenggelam di bawah layar, lalu menyembul naik (*peeking bounce*) dengan kurva `easeOutBack`.

### 2. Section "Tentang Saya" (Minimalis & Editorial)
- **Latar Belakang Merah Solid (*Bold Crimson Red* `#d11a2a`)**.
- **Tipografi Putih Bersih (*Pure White* `#ffffff`)**:
  - Judul: **`Tentang Saya`**.
  - Paragraf editorial bersih dan terstruktur (kartu/tech-stack ditiadakan agar fokus, bersih, dan lapang).
- **Karakter 3D Berdiri Ramping di Samping Kanan (*Refined & Smaller Scale*)**:
  - Karakter turun secara dinamis dan berdiri di sisi kanan layar (`scaleAbout = 0.068`), proporsional dan tidak menutupi teks.
  - Tubuh karakter miring sedikit ke kiri menghadap teks *Tentang Saya*.
- **100% Fully Responsive**:
  - Dioptimalkan untuk Mobile, Tablet, Laptop, dan Desktop 1080p dengan transisi posisi adaptif.
