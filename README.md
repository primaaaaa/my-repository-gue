# 🎨 Editorial Cream Magazine Hero Section (Three.js 3D Character)

Halaman *Hero Section* portofolio berestetika **High-Fashion Editorial Magazine Cover** yang terinspirasi dari referensi poster majalah seni:
- **Latar Belakang Krim Mewah (*Warm Editorial Cream* `#f6f4f0`)**: Warna bersih, minimalis, dan elegan.
- **Tipografi Editorial Bergaya (*Masthead Typography*)**:
  - Teks atas terpusat: `PRESENTED BY CREATIVE DEVELOPER • 2026`.
  - Judul raksasa: **`MY portfoliO`** menggunakan kombinasi serif klasik (*Playfair Display*) dengan ligatur kursif/miring pada huruf `tf` yang dinamis.
- **Karakter Muncul dari Bawah Layar (*Peeking from Bottom*)**:
  - Karakter 3D Anda (baju `#262f53` dan gaya rambut ikal dengan untaian spiral) muncul dari tepi bawah layar, membingkai bagian bawah judul majalah persis seperti model di foto referensi.
  - Tatapan mata dan kepala karakter menengadah ke atas mengikuti kursor mouse Anda secara presisi 3D.
  - Klik di mana saja pada layar untuk membuat karakter melambaikan tangan dari bawah.
- **Kamera Terkunci Stabil (*Fixed Framing*)**: Bebas dari pergeseran orbit kamera yang tidak diinginkan.

---

## 🚀 Cara Menjalankan

Jalankan perintah berikut di PowerShell / terminal:
```bash
python -m http.server 3000
```
Buka browser pada:
👉 **[http://localhost:3000](http://localhost:3000)**
